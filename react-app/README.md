# Omega Titanio · react-app

Código del frontend en React. La documentación completa (instalación, integración con el backend, sesión, roles y pruebas) está en el [README principal](../README.md).

Comandos rápidos (desde esta carpeta, con el backend corriendo en `http://localhost:8080`):

```bash
npm install     # una sola vez
npm run dev     # http://localhost:5173
npm test        # pruebas con Karma
npm run build   # versión de producción
```
